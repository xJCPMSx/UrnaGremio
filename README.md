# Urna Eletrônica — Grêmio Estudantil 🗳️🏫

> Simulador interativo web de urna eletrônica inspirado no sistema eleitoral brasileiro, desenvolvido para votações e eleições de grêmios estudantis.

## 📖 Visão Geral

Aplicação web que recria a experiência de votação da urna eletrônica:
- Teclado numérico na tela e suporte ao teclado físico.
- Exibição de foto do candidato, número, nome da chapa e partido.
- Botões de **Branco**, **Corrige** e **Confirma** com reprodução sonora característica.
- Apuração simplificada de votos ao final da sessão eleitoral.

---

## 🚀 Como Executar

Abra o arquivo `index.html` em qualquer navegador web.
